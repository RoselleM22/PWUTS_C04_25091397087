
# Kelola Kost - Fitur Pembayaran

## Deskripsi
Kelola Kost merupakan website untuk membantu penghuni kost melihat informasi tagihan dan melakukan pengajuan pembayaran.

Proyek ini dibuat untuk memenuhi Ujian Tengah Semester mata kuliah Pemrograman Web.

## Fitur Website
1. Dashboard penghuni yang menampilkan ringkasan tagihan.
2. Halaman riwayat pembayaran.
3. Filter riwayat pembayaran berdasarkan status.
4. Formulir pengajuan pembayaran kost.
5. Validasi input menggunakan JavaScript dan jQuery.
6. Navigasi halaman menggunakan AJAX.
7. Tampilan responsif untuk desktop dan perangkat seluler.

## Teknologi
- HTML
- CSS
- JavaScript
- jQuery
- AJAX

## Cara Menjalankan
1. Buka folder proyek menggunakan Visual Studio Code.
2. Jalankan file `index.html` menggunakan ekstensi Live Server.
3. Gunakan menu Dashboard, Pembayaran, dan Bayar Kost untuk mencoba fitur website.

## Catatan
Data tagihan dan pembayaran yang ditampilkan merupakan data contoh untuk demonstrasi. Formulir pembayaran pada versi ini masih berupa simulasi dan belum menyimpan transaksi ke database.
